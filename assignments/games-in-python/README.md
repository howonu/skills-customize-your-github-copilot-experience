# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a command-line Hangman game using Python strings, loops, conditionals, and user input. Practice tracking guesses and giving the player clear feedback as they try to uncover a hidden word.

## 📝 Tasks

### 🛠️ Set Up the Word and Letter Guesses

#### Description
Create a Hangman game that randomly selects a hidden word from a predefined list and lets the player guess its letters.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses from the player
- Display the correctly guessed letters and underscore placeholders for letters that have not yet been guessed (for example, `_ _ _`)


### 🛠️ Track Attempts and Finish the Game

#### Description
Track incorrect guesses and end the game when the player either reveals the whole word or runs out of attempts.

#### Requirements
Completed program should:

- Track and display how many incorrect guesses the player has remaining
- End the game when the player guesses the word or runs out of attempts
- Display a win message when the player guesses the word and a lose message when attempts run out
